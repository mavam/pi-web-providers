# Webfox brand assets

| Color | Hex |
| --- | --- |
| Orange | `#FF651A` |
| Midnight navy | `#171A35` |
| Rear-ear accent | `#E53405` |
| White | `#FFFFFF` |

Use `webfox-lockup.svg` on light backgrounds and `webfox-lockup-dark.svg` on
dark backgrounds. The dark version replaces midnight navy with white, leaving
orange, the rear-ear accent, and transparent areas unchanged. Neither version
has an outline or a background.

The matching PNGs are 1630 × 456 pixels. The README selects the dark PNG with
`prefers-color-scheme`, with the original light PNG as the fallback.

The original symbol, wordmark, monochrome, white, and brand-sheet assets remain
available as supplied.
