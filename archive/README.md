# pi-web-providers release archive

This directory preserves the published pi-web-providers changelog through
v3.5.1. Release files are unchanged; the original `v…` Git tags and GitHub
releases remain in place.

Webfox starts its own history at v0.1.0 in the root `changelog/` directory and
uses `webfox-v…` Git tags. This archive is not an input to Webfox version selection.

Inspect the old history without changing the active project:

```sh
uvx tenzir-ship --root archive release version
```
